🌾 KrishiSetu

KrishiSetu is a digital platform designed to make the agricultural procurement process easier and more organised for farmers.

The main idea is simple: instead of farmers reaching a procurement centre and waiting in a long, uncertain queue, they can book a suitable date and time slot in advance, get their queue position, and track the procurement status.

🚜 Key Features
👨‍🌾 Farmer registration & login
📅 Advance slot booking
🎫 Digital token & queue position
⏱️ Estimated waiting time
🏢 Procurement centre management
👨‍💼 Operator dashboard
📊 Admin dashboard
🔔 Procurement status & notifications
🌐 English & Hindi support
📶 Low-network mode


🛠️ Tech Stack

React • Vite • JavaScript • Tailwind CSS • Recharts • Lucide React
